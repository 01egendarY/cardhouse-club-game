## Version 1.0 — 2026-10-14

Published on Roblox and checked by the owner with a friend. The GitHub release records this update and its presentation media; it does not install or deploy the game.

### Added

- Subtle legal-card hints for Durak defenses/transfers and Goat beating combinations.
- A three-minute card-game cooldown after voluntarily leaving an unfinished match.
- A required-turn inactivity warning at 30 seconds and removal after 60 seconds.
- New real-gameplay screenshots and a 48-second trailer, including dark Card Cosmos footage.

### Changed

- More compact phone/tablet navigation, persistent ability buttons and expanded card-game panels.
- Improved shop cards, awards spacing, trump visibility and leave confirmation.
- A larger Cloudbloom Ascent start platform with approaches around the first landing.

### Fixed

- Sky-island falls retain the active route and return players to their checkpoint.
- Tea ceremony avatar visibility.
- Repeated light-field return popups removed while checkpoint returns remain active.
